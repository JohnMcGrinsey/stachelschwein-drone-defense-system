# Stachelschwein DDS Scanner v0.1

Benannte Unit. Nur hören. Raspberry Pi 5 als Gehirn, zwei Ohren, HTTPS an die Zentrale auf Wunderglobe.

## Ohren

1. **Remote ID** (ein Funk, nicht vier Streams): ESP32-S3-MINI-1U plus Außenantenne. EU Direct Remote ID seit 1. Januar 2024.
2. **Akustik** (vier MEMS-Kapseln, ein Array): Seeed ReSpeaker XVF3800. Nicht vier Kameras. Glasfaser-FPV hat keinen Funk, deshalb das Array.

Ohr 3 (Breitband-Funk) und Ohr 4 (Kamera) warten auf v0.2.
