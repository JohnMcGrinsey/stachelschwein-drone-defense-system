# Haustest

Flieg einen Vogel den du besitzt auf eine Kiste die du besitzt. Nur über eigenem Grund, Open Category.

1. Scanner auf Balkon oder Dach. Die Handy-App zählt.
2. Angreifer: C1/C2 (DJI Air, Parrot) oder DIY mit Dronetag DRI. Eine C0-Mini sendet oft keine Remote ID: das ist der Akustik-Test.
3. Log: Zeit, Abstand, gehört oder nicht, Wind, Falschalarme.
4. Dunklen Anflug wiederholen. RID schweigt, Akustik soll anschlagen.

Das beweist: die Kiste lebt und kann DETECTION tragen. Das beweist keine Stadtzelle und keinen Shahed.
